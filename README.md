# 🏠 Real Estate FAQ Bot

An intelligent Real Estate FAQ Assistant built using Python, Streamlit, and NLP techniques to efficiently answer property-related queries using compressed market data and buying processes.

---

## 📌 Problem Statement
Property buyers often struggle to find quick and accurate answers regarding prices, legal documentation, loans, and purchasing processes. Manual customer support is time-consuming and inefficient.

---

## 🚀 Solution
This project provides an automated FAQ chatbot that answers common real estate buyer questions using Natural Language Processing (NLP) techniques such as TF-IDF vectorization and cosine similarity.

---

## ✨ Features
- Interactive web-based chatbot interface
- Efficient NLP-based question matching
- Compressed real estate market and buying process data
- Lightweight and fast response system
- Easily extendable for real-time data or LLM integration

---

## 🛠 Tech Stack
- Python
- Streamlit (Frontend)
- Scikit-learn (TF-IDF, Cosine Similarity)
